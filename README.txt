Lokesh Music Academy website
============================

Files:
- index.html: responsive single-page website
- images/lokesh-at-keyboard.jpg: homepage hero photo
- images/lokesh-portrait.jpg: teacher portrait in the About section

To preview: open index.html in a browser.
To publish free: upload the ZIP or the extracted project folder to https://app.netlify.com/drop.
Keep the images folder alongside index.html when uploading the project folder.
The enquiry form opens WhatsApp with a prefilled message; it does not send automatically.
